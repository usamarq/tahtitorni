The BSc capstone at FAST-NUCES, as a team: PHARMER, short for Precision Home
Agriculture and Refined Market Evaluation Resource.

The system pairs an embedded platform with machine learning models to automate
and optimize vertical farming: an IoT-based setup monitors environmental
conditions and predicts crop yield and market value, and a web platform plus
mobile application handle remote monitoring, so farmers can make data-driven
decisions about crop management.

I led the development of the embedded system and its integration with the
machine learning models. The linked repository is a credited fork of the team's
work.
