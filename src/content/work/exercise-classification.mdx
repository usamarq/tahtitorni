A Multi-Modal Data Fusion course project at the University of Oulu: classifying
physical exercises from more than one kind of signal at once.

I designed and implemented machine learning models that classify exercises
using multi-modal data from wearable sensors and depth cameras, and explored
various data fusion techniques to improve classification accuracy.
