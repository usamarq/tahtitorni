A BSc project at FAST-NUCES: a home automation system built on the TM4C
microcontroller, offering air quality and temperature monitoring along with
intruder detection.

I wrote the firmware in C using Keil uVision4 libraries: embedded systems and
IoT work from the hardware side of the degree.
