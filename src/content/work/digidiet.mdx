A Human-Computer Interaction course project at the University of Oulu, and the
one pure design entry in this list: the UI for DigiDiet, a mobile app for
finding food that aligns with dietary preferences.

I created user flow diagrams, wireframes and interactive prototypes in Figma,
applying user-centered design principles and iterating on feedback to improve
usability and accessibility.

I then evaluated the high-fidelity prototype with people in two sessions: a
think-aloud session with three participants (a startup CTO, a full-stack web
developer and a computer science master's student), and a co-operative
evaluation session with three University of Oulu master's students. Both were
guided by four set questions, on simplicity, the main and secondary features,
navigation, and how the features relate. I reported what the sessions showed
and the design changes they led to: larger home-screen tiles for the two main
features, restaurant reviews, and map zoom and filters.

Design work only: there is no code repository for this project.
