A Human-Computer Interaction course project at the University of Oulu, and the
one pure design entry in this list: the UI for DigiDiet, a mobile app for
finding food that aligns with dietary preferences.

I created user flow diagrams, wireframes and interactive prototypes in Figma,
applying user-centered design principles and iterating on feedback to improve
usability and accessibility.

Design work only: there is no code repository for this project.
